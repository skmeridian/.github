# Salty Poker Network

A legal online poker network for Texas.

The [Salty Poker Network](https://salty.poker) is building a legal online
poker network for Texas, on the Texas private club model. Members are
verified and geofenced, and the operator earns a fixed seat fee instead of
taking from the pot.

- 📍 Austin, Texas
